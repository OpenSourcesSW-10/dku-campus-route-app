# coordinate_rule.md

## 1. 기본 좌표 기준

모든 실내 지도 좌표는 PDF 및 SVG 기준의 2차원 좌표계를 사용한다.

좌측 상단(left-top)을 원점(0,0)으로 설정한다.

x 좌표는 오른쪽 방향으로 증가한다.
y 좌표는 아래 방향으로 증가한다.

---

## 2. 좌표 단위

모든 좌표 단위는 pixel(px) 기준으로 저장한다.

PDF를 SVG로 변환한 이후에도 동일 좌표계를 유지한다.

---

## 3. 층별 좌표 체계

각 건물의 층은 독립적인 좌표계를 가진다.

예시:

* DKU_ICT 1F
* DKU_ICT 2F

는 서로 다른 좌표 공간으로 처리한다.

---

## 4. room_positions 기준

방 위치 데이터는 직사각형(rectangle) 기준으로 저장한다.

사용 컬럼:

* x
* y
* width
* height

x, y는 방 영역의 좌측 상단 기준이다.

---

## 5. indoor_nodes 기준

실내 노드는 point(점) 기준 좌표를 사용한다.

사용 컬럼:

* x
* y

노드는 복도 중심선 또는 이동 가능 위치 기준으로 생성한다.

---

## 6. 출입구 연결 기준

건물 출입구는 entrance node 기준으로 연결한다.

실내 entrance node 와
실외 outdoor node 를 연결하여
실내외 통합 경로 탐색을 수행한다.
